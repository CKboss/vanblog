VanBlog 的后台接口（`/api/admin/**`）除了浏览器登录态，也接受 **API Token** ——
适合脚本、定时任务、CI 与第三方集成这类"没有登录态"的调用方。

在后台的 `系统设置 / Token 管理` 里签发、查看与吊销。

![](https://pic.mereith.com/img/8c27dee1b90fca797426c787350599b3.clipboard-2023-03-22.png)

## Token 怎么带

放在请求头 **`token`** 里（⚠️ 不是 `Authorization: Bearer`，服务端只从 `token` 这个头取）：

```bash
curl -H "token: <你的 token>" "https://你的域名/api/admin/article?page=1&pageSize=5"
```

| 返回 | 什么意思 |
| --- | --- |
| **401** | Token 缺失、无效、已过期，或已被吊销 |
| **403** | Token 有效，但这个账号没有这项权限（协作者才会遇到；API Token 不会） |

## 权限有多大

::: danger API Token 等于超管，能调所有后台接口

签发时它的身份就写死成超管，所以**不受协作者那套权限范围限制**：改账号密码、改站点设置、
删文章、导出整站备份，它都能做。因此：

- 不要写进前台代码、不要提交进仓库、不要贴到聊天或截图里；
- 只想让别人读文章内容的话，用匿名接口 `/api/public/**`，别发 Token；
- 一个用途一个 Token（便于单独吊销），别全站共用一个。

:::

哪些接口要 Token、哪些是故意匿名的（登录、找回密码、初始化、caddy 回调），
见 [API 参考 → 哪些接口不需要登录](../reference/api.md#哪些接口不需要登录)。

## 有效期

- 新签发的 API Token 默认 **365 天**，可用 `VANBLOG_API_TOKEN_TTL_DAYS` 调，范围 **1 ~ 36500 天**。
  ⚠️ 填 `0`、填字母、或干脆不设，都会回落成 **365**（不会变成 1 天）。
- ⚠️ 更早的版本默认是 **100 年**（等于永不过期，泄露一次就长期有效）。**已经签发的 Token 不受改动影响** ——
  每个 Token 的有效期在签发时就写进库里了；介意的话到后台吊销、重新签发。
- 浏览器登录态的有效期是另一套：后台「登录凭证(Token)有效期(秒)」，默认 **7 天**。
- 过期由 JWT 自己判定，"有没有被吊销"则是查库（`tokens` 集合里那条记录的 `disabled` 字段）。

## 什么时候会突然全部失效

脚本全线 401 时，先对照这张表：

| 你做了什么 | 结果 |
| --- | --- |
| 后台保存账号信息 / 改密码 | 吊销**全部** Token（含 API Token），约 1 秒后生效 |
| 用日志里的恢复密钥重置密码 | 同上 |
| **修改或删除**一个协作者 | ⚠️ 吊销所有非超管的登录态，而 **API Token 也在这个范围里**，会被一起吊销 |
| 新建一个协作者 | 不影响已有 Token |
| 从整站备份恢复 | Token 跟着备份回来，但 JWT 密钥是**启动时**读的 ⇒ 先重启一次容器，再重新登录 |
| 在 Token 管理里点吊销 | 只吊销那一个 |

最容易踩的是"改协作者"那条：你只是调了某个协作者的权限，CI 里的备份脚本就开始 401。
遇到这种情况到 Token 管理里重新签发一个即可。

## 备份与迁移

登录态与 API Token 都存在同一个 `tokens` 集合里，会随[整站备份](./backup.md#整站备份推荐)一起走，
所以换机器恢复之后**不用重新签发**（但要先重启容器让 JWT 密钥对齐，见上表）。

`./vanblog.sh` 的备份 / 校验 / 演练等命令也走这条路：设 `VANBLOG_ADMIN_TOKEN` 环境变量，
或在后台签发一个 API Token 给它。

## 脚本里怎么拿 Token

推荐直接在后台签发 API Token（长期有效、可单独吊销）。
也可以用账号密码换登录态：

```bash
curl -sS -X POST "https://你的域名/api/admin/auth/login" \
  -H 'Content-Type: application/json' \
  -d '{"username":"你的账号","password":"你的密码"}'
# 成功时返回 {"statusCode":200,"data":{"token":"…","user":{…}}}
```

⚠️ 但登录接口有防爆破限次（默认同一 IP **5 次 / 300 秒**），而且登录态默认只活 7 天，
所以脚本别走这条路 —— 反复登录很容易把自己锁在门外。

## API 文档

运行时的 `/swagger`（Swagger UI）与 `/swagger-json` **默认是关闭的**：它匿名可读，
等于把整个后台接口面（一百多条路由 + 登录请求的形状）摊给未登录用户。

需要时给容器设 `VANBLOG_SWAGGER=true`（**只认字面 `true`**）并重启，排查完建议关回去。

后台两个入口的行为不一样：`Token 管理` 的「API 文档」按钮会**先探一下** `/swagger-json`，
开着就打开 `/swagger`，关着就提示你该设哪个环境变量、并改开仓库里的接口文档；
「关于」页的入口**不探测**，直接指向仓库里的文档。所以两种状态都不会留下死链接。

> 鉴权规则、匿名接口清单、响应信封（含未初始化时的 233）与限流分桶，见 [API 参考](../reference/api.md)。
