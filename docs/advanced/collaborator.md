VanBlog 支持添加自定义权限的协作者用户。

你需要在 `站点管理/系统设置/用户设置` 中进行相关设置:

![用户设置](https://www.mereith.com/static/img/726f7b197b240a923b8473106d3d1200.clipboard-2022-09-03.png)

<!-- more -->

## 账户权限

协作者账户**默认只有下面这些**（不需要勾选任何权限就有）：

- **查看**：文章与草稿的列表和详情、分类、标签、图片、附件、文章/草稿的**回收站列表**、
  文章的**历史版本**（列表与单条内容）
- **上传**：图片、附件
- **其它**：把文章/草稿**导出为 Markdown**（含图片打包）、按链接搜文章、查图片被哪些文章引用、
  检测图片里的隐写水印

除这些之外**一律拒绝**：没有对应权限的接口会直接报错，后台也不会显示那个入口。
权限判定过程出错时同样是**拒绝**（不会因为一个异常就把后台敞开）。

您可以在创建协作者时额外授予一些权限：

- 创建-文章
- 修改-文章
- 删除-文章
- 发布-草稿
- 创建-草稿
- 修改-草稿
- 删除-草稿
- 删除-图片
- 替换-图片
- 删除-附件
- 所有权限

![权限授予](https://www.mereith.com/static/img/73ef0844436b7eee71d41b4b0c2033d2.clipboard-2022-09-03.png)

除了拥有 `所有权限` 的协作者外，登录后都将看到精简的 UI：

![协作模式](https://www.mereith.com/static/img/bbb3252731394960a7b307248a28a107.clipboard-2022-09-03.png)

::: warning 勾「所有权限」等于交出站点，请照实评估

代码里的判定就是"含 `all` 则放行全部后台路由"（`provider/access/access.guard.ts`），所以它不是
"多几项编辑权限"，而是**除账号本身之外的全部能力**。具体能做到：

- **改管理员口令**：走改密码接口即可，改完 `disableAll()` 会吊销现有令牌（含真管理员的）。
- **签发 API Token**，而 API Token 签的是 `{sub:0, role:'admin'}`，`AccessGuard` 见 `user.id == 0`
  直接放行 ⇒ **等价超管**，且不受协作者权限约束、有效期默认 365 天。
- **下载整站备份**：归档里是整个数据库 —— 全部口令的 scrypt 哈希、`settings` 里的 **jwt 密钥**
  （拿它可以直接签管理员令牌，不需要破任何密码）、全部文章。
- **通过流水线在容器内执行任意代码**：流水线是站长写的自定义 JS，能在 server 进程里跑，
  等于容器内的代码执行（可以读配置、连数据库、访问内网）。

所以「所有权限」适合"第二个自己"，不适合外包或临时编辑。只给写作/图片/附件那几项时，
协作者看不到分类与文章的访问密码（见下面），也进不了系统设置、备份、Token 与流水线。

:::

::: tip 协作者看不到加密密码

分类的访问密码对协作者是**脱敏**的（`GET /api/admin/category/all?detail=true` 不给密码字段），
文章侧同理：任何接口都只回「有没有设密码」这个布尔，不回密码也不回哈希。
协作者的口令与管理员一样存 **scrypt** 哈希，详见 [安全与加固](./security.md#口令存储scrypt登录时自动迁移)。

:::

### 作者问题

在创建文章或草稿时，默认的作者为当前登录账户昵称（如果是管理员则是站点管理中设置的作者名称）。

此作者也会显示在前端的版权声明中。
