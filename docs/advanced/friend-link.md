VanBlog 支持 `友情链接` 展示，

::: tip 友链页默认就是开着的

友链页固定在 **`/link`**，而且默认导航里就有「友链」这一项 —— **不需要**去布局设置里开什么开关
（后台并没有「显示友情链接」这个选项）。如果你的导航里没有它，说明导航被改过：到
`站点管理/数据管理/导航配置` 加一条指向 `/link` 的菜单即可，见 [自定义导航栏](./custom-nav.md)。

:::

![友情链接展示](https://pic.mereith.com/img/8daaa28eeac7e3a3de0e4717026f54ab.clipboard-2022-08-15.png)

## 增删改查

进入后台 `站点管理/数据管理/友情链接` 即可，需要注意的是不同友链的名字必须不同，相同的话会覆盖掉之前的条目。

## 自定义页面文案

友链页列表上方的介绍、列表下方的申领要求（以及本站信息）可以在 `站点管理/系统设置/站点配置/布局设置` 里改：

- **友链页介绍文案**：列表上方那一行。留空则仍是「以下是本站的友情链接，排名不分先后：」。
- **友链页底部文案**：列表下方的 Markdown。留空则仍是升级前的申领要求与本站信息。

底部文案里可以用占位符插入当前站点信息：`{{siteName}}`、`{{description}}`（网站描述）、`{{url}}`（当前访问域名）、`{{logo}}`（站点 / 作者头像）。保存后会触发前台增量渲染。

伙伴名可以是 URL（例如误把地址填进「伙伴名」）。后台删除会按名字查询，编辑会更新原来的那一行，而不会因为名字里有 `://` 就删不掉或另存一条。
