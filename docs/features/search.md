VanBlog 支持对文章进行搜索：顶栏搜索弹层（快捷键 <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>K</kbd>）
用于快速定位，独立的 **`/search` 结果页**用于认真翻结果。

<!-- more -->

## 博客搜索

VanBlog 会在导航栏右侧显示搜索图标，你可以点击图标或使用快捷键 <kbd>Ctrl</kbd> + <kbd>K</kbd> 打开搜索框。

弹层会按你输入的关键词匹配文章的**标题、标签、分类与内容**，并给出「查看全部结果」入口，
跳到 `/search?q=<关键词>` 结果页。

![搜索](https://pic.mereith.com/img/a6ea194aef7720593443227dc1acf347.clipboard-2022-08-16.png)

::: tip

- 按下 <kbd>Esc</kbd> 可关闭搜索卡片
- 打开后焦点进入搜索框（含 iPhone Safari 点图标打开）；<kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> 只在弹层内循环
- 输入框为 `type="search"`，移动端键盘显示「搜索」；Safari 关闭自动纠正，以免干扰关键词
- <kbd>↑</kbd> / <kbd>↓</kbd> 在结果间移动，<kbd>Enter</kbd> 打开当前结果；清除按钮可用 <kbd>Enter</kbd> / 空格，悬停只变颜色和透明度、不再放大
- 不支持拼音搜索

:::

## `/search` 结果页与静态索引

结果页是一个 **ISR 静态壳 + 浏览器内搜索**：server 会生成一份紧凑的静态索引
`/static/search/index.json`（每篇只收标题、路径、标签、分类和 ≤200 字的纯文本摘要），
页面加载后在浏览器里对着它做匹配、排序、高亮与分页 —— **搜索本身零数据库成本**，
索引是静态文件，还能被 CDN 缓存。

- **排序**：三档（标题命中 > 标签/分类命中 > 仅摘要命中），档内按命中次数、再按新近度；
- **高亮**：命中词在标题与摘要里用 `<mark>` 标出；
- **多词 = AND**：按空白切词，每个词都至少要在标题/标签/分类/摘要之一出现；
- **收录范围与 sitemap 完全一致**：隐藏文章、加密/私有文章、私有分类下的文章、
  软删文章、`publishAt` 未到点的定时文章都**不会**进索引（有测试钉住这两个集合相等）；
- **索引什么时候更新**：与 RSS/sitemap 同一条触发链（后台保存文章、整站渲染等，60 秒防抖），
  另有每小时一次的兜底 cron。所以「刚发布就搜」最多延迟一分钟量级；
- **回退**：索引缺失、过期或被截断时，结果页干净地回退到服务端搜索接口
  `GET /api/public/search`（顶栏弹层一直用的就是它），搜索永远不会变成一块空白；
  没有 JS 时页面也给了一个直接打服务端接口的出口。

相关环境变量（默认值都不用改，详见 [环境变量](../reference/env.md#内容功能)）：
`VANBLOG_SEARCH_INDEX`（总开关，默认开）、`VANBLOG_SEARCH_INDEX_MAX_DOCS`（默认 2000 篇，
最新的优先）、`VANBLOG_SEARCH_INDEX_SNIPPET_CHARS`（默认 200 字）。

::: warning 诚实的局限

- **子串匹配，不分词、不容错拼写、没有拼音**：搜「备份」能命中「整站备份」，
  但打错一个字（`dockre` vs `docker`）就搜不到 —— 这是刻意不引搜索库换来的极简，不是 bug；
- **摘要只有 ≤200 字**：关键词在正文很深处时客户端索引可能搜不到，此时请用服务端回退
  （顶栏弹层，或结果页提示的降级路径），它对全文做匹配；
- **新鲜度 = 索引最后一次生成的时间**：刚改完的文章最多要等一轮防抖/兜底 cron；
- **超过 2000 篇**时索引只含最新的一部分（页面会提示），全量搜索走服务端回退。

:::
