VanBlog 可以配置一系列的站点配置项，可在 `站点管理/系统设置` 中查看。

包括三类：

- 基本设置：博客系统正常运行必须的配置
- 高级设置：博客系统的进阶选项
- 布局设置：改变前台展示布局的设置（含**界面风格**、每页文章数、分类页默认展开、友链页 / 关于页文案、导航栏左侧显示网站名或 logo）。手机端顶栏网站名相对整页宽度居中，电脑端仍在左侧。前台首页和 `/page/n` 分页在多页时可以输入页码跳转；非法或超出范围的数字不会跳转。总页数跟随「每页文章数」。

![站点设置](https://pic.mereith.com/img/abb9afde6ccf1ee82cfe41e083df4daf.clipboard-2022-08-15.png)

所有设置项详见 [参考 → 站点配置](../reference/config.md)。

## 界面风格（Apple 风格）

`站点管理 / 站点信息 / 布局设置 → 界面风格` 可以切换前台的视觉语言：

| 选项 | 说明 |
| --- | --- |
| **Apple 风格**（默认） | 参考 [Apple Developer News](https://developer.apple.com/news/) 的排版：SF Pro 字体栈、17px 正文、单列发丝线分隔的列表、毛玻璃导航栏、苹果蓝强调色、胶囊按钮、18px 圆角卡片 |
| 默认 | VanBlog 原本的卡片式外观（一张张带阴影的白卡） |

切换只影响**样式**，不改任何页面结构，也不影响你自己写的自定义 CSS（`启用定制化` 里的内容仍然生效，需要覆盖时它的优先级更高）。随时可以切回来。

Apple 风格具体做了这些事：

- **导航栏**：`saturate(180%) blur(20px)` 毛玻璃 + 底部发丝线，高度 52px，链接 14px 灰字、hover 变深。
- **首页/分类/标签列表**：单列 980px，**条目之间用发丝线分隔**而不是浮起的卡片；标题 28px/600 左对齐（hover 变蓝），下面一行 13px 灰色元信息（日期 · 分类 · 阅读数），摘要 17px/1.6 最多露 4 行，「阅读全文」变成蓝色文字链接带 `›`。
- **作者卡片**：从右侧栏移到**页首简介条**（Apple News 没有侧栏），头像 56px、名字与简介横排。
- **文章详情页**：780px 阅读栏，标题 40px/600，元信息行下一道发丝线；标题层级用**字重**区分（h2 28px、h3 22px）；引用块做成浅灰圆角 callout（2px 灰色左边条）；代码块浅灰填充 + 12px 圆角、**不描边**；表格只留行间发丝线（无外框、无斑马纹）；目录（TOC）留在右侧 220px 细栏、当前项蓝色。
- **不用线框**：Apple 的层次靠**留白 + 发丝线 + 浅灰填充**，不靠描边。所以文章卡、作者卡、导航、分页、输入框、代码块、提示容器全部**无描边**；需要边界感的地方（友链卡片、正文里的提醒/版权/打赏小块）用 `#f5f5f7` 浅灰填充 + 圆角。整份皮肤里只剩 6 处单边发丝线：导航底部、列表条目之间、文章元信息下、引用块左边、表格行之间、页脚上方。
- **标题右侧的「编辑」和复制按钮**压成 13px 次要灰、常规字重（组件里原本是近黑 `text-dark`，在 Apple 排版里太重），hover 才变蓝。
- **时间线**：年份 32px/600，竖轨改成发丝线，条目 hover 变蓝。
- **分类/标签**：胶囊 chip，浅灰底、选中/hover 蓝底白字。
- **分页**：无描边的安静文字，hover 浅灰胶囊，当前页浅灰填充 + 半粗。
- **友链卡片**：`#f5f5f7` 浅灰填充 + 18px 圆角、无描边，hover 只抬升 2px（原来是 -8px，太跳）。
- **页脚**：发丝线上边框 + 13px 灰字。
- **暗色模式**：整套令牌反转（画布 `#000`、表面 `#1d1d1f`、强调色 `#2997ff`），图片自动降到 `brightness(.92)`，跟 Apple 官网一致。
- **移动端**：字号收一档（标题 22px、正文 16px），目录栏隐藏，简介条收紧。

设计令牌（都写在 `packages/website/styles/apple.css` 顶部的 CSS 变量里，想微调直接改这些值）：

| 令牌 | 亮色 | 暗色 |
| --- | --- | --- |
| `--ap-canvas` 画布 | `#ffffff` | `#000000` |
| `--ap-surface` 表面 | `#ffffff` | `#1d1d1f` |
| `--ap-surface-3` 内嵌面（代码/引用/chip） | `#f5f5f7` | `#2c2c2e` |
| `--ap-text` 主文字 | `#1d1d1f` | `#f5f5f7` |
| `--ap-text-2` 次要文字 | `#6e6e73` | `#a1a1a6` |
| `--ap-hairline` 发丝线 | `#d2d2d7` | `#424245` |
| `--ap-accent` 强调色 | `#0071e3` | `#2997ff` |
| `--ap-radius-card` / `--ap-radius-img` | 18px / 12px | 同 |
| `--ap-content` / `--ap-read` | 980px / 780px | 同 |

::: tip 实现方式

所有规则都挂在 `[data-ui="apple"]` 选择器下，由 `components/Layout` 按站点设置输出到最外层容器（并同步到 `<html>`），所以它是一层**可整体开关的皮肤**，不会污染默认风格的样式，也不会和你的自定义 CSS 打架。

`packages/website/__tests__/appleTheme.spec.ts` 里有一组守卫测试：任何选择器逃出 `[data-ui="apple"]` 作用域、或者皮肤里出现了四面包围的描边（`border: 1px solid …`），测试就会红。

:::
