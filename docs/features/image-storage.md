## 设置图床

### 内置图床

VanBlog 带有内置的图床实现，无需任何配置，开箱即用。后台插入图片时，常会把当前访问域名写成绝对地址（`https://你的域名/static/img/...`）。换域名后请用「图床设置」里的改写工具更新文章链接，见 [域名变更后文章里的图片打不开](../faq/usage.md#域名变更后文章里的图片打不开)。

::: tip

为防止更新后丢失数据，请在部署时确认目录映射正常。

:::

### 第三方图床

VanBlog 可以对接第三方图床，是基于 [picgo-core](https://picgo.github.io/PicGo-Core-Doc/) 实现的。

#### 支持列表

- 七牛图床
- 腾讯云 COS
- 又拍云
- GitHub
- SM.MS
- 阿里云 OSS
- Imgur

生成后，进入后台`站点管理/系统设置/图床设置`，选择 `OSS` 图床，并把生成的配置文件复制过去，比如我用的七牛云图床，就像下面这样：

## 其他功能

### 自动压缩

无论使用何种图床，VanBlog 都支持上传图片自动压缩。默认输出 **WebP**；也可以在后台选 **AVIF**（通常更小，现代浏览器已广泛支持）。在编辑器或图片管理中上传图片时，VanBlog 会在收到图片信息的时候，先进行压缩，再保存到对应图床。只影响**新上传**，不会改写已经存好的历史文件。

这个功能默认是开启的（WebP）。想关闭或改成 AVIF，请在后台 `站点管理/系统设置/图床设置` 中调整 `自动压缩` 和旁边的 `压缩格式`。

**运行时依赖：** WebP 仍用 Alpine 镜像里的 `libwebp-tools`（`cwebp`）。AVIF 优先用 [sharp](https://sharp.pixelplumbing.com/) `0.32.6`（与前台相同；官方 all-in-one 镜像里前台 standalone 自带 musl 预编译）。服务端若在 Alpine 上加载不到可用的 sharp（服务端构建阶段是 Debian），会回退到 `avifenc`（`apk` 包 `libavif-apps`，已写入官方 Dockerfile）。压缩失败时会保留原图，与原先 WebP 失败时的行为一致。

![自动压缩设置](https://pic.mereith.com/img/6f00ddb9f4051d05aa030cdf6ce3404f.clipboard-2023-04-14.png)

### 大图自动缩放

手机随手拍的照片常有四五千像素宽，博客里根本用不上，白白占流量。开启后，**长边超过上限的图片会在上传时等比缩小**（默认上限 `1920`，即常说的 1080p 级），小图一个像素都不动，也**绝不会放大**。

- 位置：后台 `站点管理/系统设置/图床设置` → `大图自动缩放` + `长边上限`；填 `0` 表示不限制。
- 顺序是 **缩放 → 隐写水印 → 压缩**，所以缩放不会影响水印的读取。
- 动图（GIF）和 SVG 不缩放：缩放会丢帧 / 失去矢量特性。
- 只影响**新上传**，不改写已有文件。

实测：一张 2400×1600 的 JPEG（2.3MB）→ 1920×1280 的 WebP（约 970KB，噪声图是最坏情况，真实照片会小得多）。

### 缩略图

开启后，上传时会额外生成一张小图（默认 **300px 宽的 WebP，约 10KB**），存在 `/static/img/thumb/` 下，并记录在图片信息的 `缩略图` 字段里。

「图片管理」默认用**小图模式**加载这些缩略图，一屏能放更多张、翻页快得多（点开任意一张仍然预览原图）；右上角可切回**大图模式**。

存量图片不会自动补，点图片管理右上角的 **补缩略图** 一次性生成（已有缩略图的自动跳过，只处理本地存储的图片）。删除图片时缩略图会一起删掉。

### 可见水印

无论使用何种图床，VanBlog 都支持上传图片自动添加水印（右下角半透明灰色文字，**默认关闭**）。在编辑器或图片管理中上传图片时，VanBlog 会在收到图片信息的时候，先进行水印转换，再保存到对应图床。

想要看不出来又能验真的水印，请用下面的[隐写水印](#隐写水印肉眼不可见)。

在后台 `站点管理/系统设置/图床设置` 中，开启水印并输入水印文字即可。水印文字可以包含 `.`，例如 `example.com`。

![水印设置](https://pic.mereith.com/img/6f00ddb9f4051d05aa030cdf6ce3404f.clipboard-2023-04-14.png)

::: warning 当前限制

- 后台中但凡表单中有上传按钮的选项，不走水印逻辑。
- 由于使用了 [jimp](https://github.com/jimp-dev/jimp/) 库做水印，字体用了 `fnt` 格式，所以暂不支持中文字符作为水印。
- 宽高小于 128px 的图片可能会加不上水印
- 水印会加到图片右下角，带透明度的灰色字体。
- 水印目前只支持上传 `png`、`jpg` 等常见格式，暂不支持动图。

如果谁有更好的 `nodejs` 水印方案，请提 `issue` 或者直接联系我，后续会支持使用自定义图片做水印。

:::

### 隐写水印（肉眼不可见）

嫌可见水印难看、又想在图片被盗用时拿出证据？用**隐写水印**：把一段文字藏进像素里，画面上完全看不出来，但可以从图片里读回来。

- 开关与内容：后台 `站点管理/系统设置/图床设置` → `隐写水印`、`隐写内容`。
- 内容留空时自动写 **`域名|上传者|上传时间`**（例如 `www.example.com|JiangOil|2026-09-12T07:40:00Z`），最多 200 字节，支持中文。
- 验证：图片管理里对着图片**右键 → 检测隐写水印**，或用工具栏的 **检测水印** 直接上传一张图来验（也接受外部图片）。

**原理**：图片切成 8×8 的块，用密钥决定的伪随机顺序取块对，把每对块的**平均亮度差**量化到一组格点上（0 落在整格、1 落在半格），每块亮度最多改动 **4 个色阶**（约 1.6%），所以肉眼看不出来；同一个 bit 会重复 3 次并做多数表决，载荷带 magic + CRC32 校验，因此**不会误报**——不是本站埋的水印一定读不出来。

**能扛住什么**：

| 情况 | 能否读出 |
| --- | --- |
| 本站压成 WebP / AVIF（有损） | ✅ |
| 被别人另存为 JPEG、截图后再压 | ✅ |
| 轻度调色、加噪 | ✅（多数表决兜底） |
| **缩放、裁剪、旋转** | ❌ 密钥与尺寸绑定，尺寸变了就读不出来 |
| 换了水印密钥 | ❌ 旧图仍然带着旧水印，但新密钥读不出 |

::: tip

- 密钥（`stegoKey`）第一次启用时自动生成并存进数据库，**不会返回给前端**；备份数据库时它跟着一起走。
- 太小的图放不下载荷时会自动降低重复次数，实在放不下就跳过水印（不影响上传，日志里能看到原因）。
- GIF 不处理（会丢帧）。
- 隐写水印和可见水印互不影响，可以同时开。

:::

### 扫描已有图片

VanBlog 支持把文章中存在的，但是不在图床记录中的图片扫描出来。

点击 `站点管理/系统设置/图床设置` 中的 `扫描现有文章图片到图床`，耐心等待即可。如果存在扫描失败的图片，会弹窗显示信息。

![扫描已有图片](https://pic.mereith.com/img/cb00c069e9fba6308151c859bd78d15d.clipboard-2022-08-15.png)

这个功能可用于检测所有文章的失效图片。

### 图片管理

进入 VanBlog 后台的 `图片管理` 模块可以对图片进行管理：

![图片管理](https://pic.mereith.com/img/5be657eaaff09be9dd4a77d968e54c21.clipboard-2022-08-15.png)

其中对着图片点右键可以显示高级菜单，包括不限于 `显示图片详细信息`、`查找被引用文章` 和 `检测隐写水印` 等。

右上角还有：

- **小图 / 大图**：切换列表用[缩略图](#缩略图)还是原图，选择会记住；
- **补缩略图**：为存量图片批量生成缩略图（管理员可见）；
- **检测水印**：上传一张图验证里面有没有本站的[隐写水印](#隐写水印肉眼不可见)。

上传图片后会自动复制图片 `Markdown 链接` 到剪切板，如需复制 `URL 链接`，请右键单击图片选择 `复制链接`。

### 外链图片转存

从别的站点（例如 CSDN）复制 Markdown 时，正文里的图片常常还是对方的外链。后台文章 / 草稿编辑器工具栏提供「外链图片转存」：扫描当前这篇的远程 `![...](http...)` 和 `<img src>`，经**现有上传管线**下载并写入本站图床（本地或已配置的 picgo / OSS），再把 Markdown 改成新地址。这是显式操作，保存或发布时不会自动改写整站文章。

会跳过：

- `data:` 内嵌图
- 相对路径（如 `/static/img/...`、`./pic.png`）
- 已经指向本站域名或图床记录里已有 `realPath` 的地址

某张下载或上传失败时，原文链接保持不变，完成后会提示失败的 URL。开启「自动压缩」时，转存走同一套管线，仍按当前的 WebP / AVIF 格式处理。

见 [编辑器](./editor.md)。

### 图片复用

每一次上传都会检测图片的 `md5` 签名，如果已经有的该图片，则不会创建新条目。而是复用之前的图片，并把之前的图片链接复制到剪切板里。

### 导出全部图片

VanBlog 支持将全部本地图床图片导出为压缩包。

你可以在后台中的图片设置中点击按钮来导出全部本地图床图片

![导出全部图片](https://www.mereith.com/static/img/dd5f0f0a1ff61a1a5d22c09fcaa8178c.clipboard-2022-09-01.png)

::: tip

OSS 图床暂不支持全部导出

:::
