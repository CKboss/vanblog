除了图片，VanBlog 还能托管任意文件（pdf / zip / epub / 数据集……），并生成可以直接分享的链接。

## 上传附件

后台左侧「附件管理」→ 右上角 **上传附件**（支持多选），单文件上限 **200MB**。上传成功后链接会自动复制到剪切板，形如：

```text
/static/file/07885c48ebdbf6466914b73f781cd3cc.年度报告.pdf
```

- 文件名前缀是内容的 MD5：**同一份文件重复上传不会产生副本**，直接返回已有链接。
- 原始文件名保留在后缀里，列表中显示的是去掉 MD5 前缀的名字；中文文件名也能正确保留。
- 附件**只存本地**（`/app/static/file/`），不受「图床设置」里 PicGo / OSS 的影响——多数图床并不接受非图片文件。
- 列表支持按文件名模糊搜索、分页，以及「导出全部附件」打成一个 zip（产物在 `/static/export/`）。

## 在文章里引用

- 编辑器工具栏的 **回形针按钮**（上传附件并插入链接）：选文件 → 上传 → 在光标处插入 `[文件名](/static/file/...)`。
- 附件管理列表的操作列：复制链接、复制 Markdown、下载、搜索引用（哪些文章用到了它）、删除。

## 下载行为与安全

| 文件类型 | 行为 |
| -------- | ---- |
| pdf、zip、图片、office 文档等 | 浏览器内联打开，可直接预览 |
| html / htm / svg / xml / js / mjs 等 | 强制下载（`Content-Disposition: attachment`） |

所有附件响应都会带 `X-Content-Type-Options: nosniff`。对 html/svg/js 强制下载是因为它们与博客同源，内联渲染等于让访客在你的域名下执行任意脚本（存储型 XSS）。

::: warning 附件链接是公开的

`/static/file/...` 和图片一样**不需要登录**就能访问。不要上传密钥、数据库备份、含个人信息的文件；需要访问控制的内容请放进[加密文章](../advanced/encrypt.md)。

:::

## 协作者权限

- 协作者默认可以查看、上传附件；
- 删除需要在协作者设置里勾选 **删除-附件**（`file:delete`），或拥有「所有权限」。

## 备份与迁移

附件都在静态目录的 `file/` 子目录下，跟着 [`/app/static`](../reference/dir.md) 一起备份即可，详见[备份与迁移](../guide/backup.md)。
