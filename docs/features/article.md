## 快速编辑文章

默认情况下，如果你登录了后台，那么前台的文章标题旁边会出现编辑按钮，你可以点击这个按钮快速跳转到后台编辑此文章。

![](https://pic.mereith.com/img/a6438e873dcbd601d23bdbf1a7fad74f.clipboard-2023-05-06.webp)

如想关闭此功能，可在后台的 `系统设置/站点配置/布局设置` 中关闭。

## 创建新文章

你可以点击 `新建文章` 按钮创建新文章。

::: warning 使用草稿

由于内置的增量渲染，新建的文章会**马上展示在前台页面**，所以更推荐的做法是 [先创建一个*草稿*](./draft.md#新建草稿)，然后再发布这个草稿。

:::

新建文章包含以下选项：

![新建文章](https://pic.mereith.com/img/c10e25ee028e3a7cd5306940ca146e80.clipboard-2023-02-27.png)

点击确定后，则以该表单为数据进行文章创建。

### 默认值

- 作者

  默认为登录者本人，下拉框内的选择范围包括 _所有的协作者的昵称_ 以及后台站点设置中的 _作者名称_。

- 自定义路径名 / slug

  文章发布后的路径将为 `/post/[自定义路径名]`。**留空时会按标题自动生成汉语拼音路径**（例如《如何部署 VanBlog》→ `/post/ru-he-bu-shu-van-blog`）；重名会依次追加 `-2`、`-3`，最后兜底 `-文章id`。只有标题里没有任何可用字符（纯表情、纯数字）时才退回数字 id（例如 `/post/123`）。数字 ID 地址始终可用。后台保存后，两种地址都会触发静态页面更新。

  这就是 VanBlog 对应 Hugo `permalinks.post = "/post/:slug"` 的做法：**没有**站点级固定链接模板，按篇文章填写即可。从 Hugo 迁移时，把旧文章的 slug 填到这里，旧的 `/post/<slug>` 才能继续打开，搜索引擎收录也不会丢。导入 Markdown 时，Front Matter 优先读 `pathname`，再读 Hugo 的 `slug`，再读形如 `/post/my-slug` 的 `url`（Hexo 的 `abbrlink` 仍可用）。

  可在这些地方设置：

  - 新建文章
  - 导入 Markdown 的确认表单
  - 发布草稿
  - 文章表格「操作 → 修改信息」，或编辑器右上角「修改信息」

  已有的老文章可以在「文章管理」右上角点 **生成拼音路径** 一次性补齐：只填路径名为空的文章，不会覆盖已有别名，可以重复执行。

  ::: warning 改了标题，别名不会跟着变

  自动生成只在「路径名为空」时发生。之后修改标题**不会**重写已有别名，否则已经分享出去、或被搜索引擎收录的链接会全部失效。确实想换，手动改这个字段就行。

  :::

  ::: tip

  如果将自定义路径名设置成 `如何部署VanBlog`（或 Hugo 旧 slug `how-to-deploy`），发布后即可通过 `/post/如何部署VanBlog`（或 `/post/how-to-deploy`）来访问。路径名只能是单段（不含 `/`），也不能是纯数字（会和文章 id 撞车）。

  :::

  从 Hugo 迁过来的完整说明见 [从 Hugo 迁移固定链接](../faq/usage.md#从-hugo-迁移固定链接)。

- 置顶优先级：数字，留空或者为 0 表示不顶置。

  置顶文章默认按时间倒序倒序，优先级高的的会置顶在前，

- 标签

  每篇文章可以有多个标签，用于索引文章。前台文章页底部会列出这些标签，每个标签前有标签图标，点进去是该标签下的文章列表。加密未解锁时不展示；首页列表卡片本来就不显示这行标签。

  标签不需要提前创建，你可以在需要标签的表单看到所有已有标签，或直接输入新标签。也可以一次粘贴多个标签：用英文/中文逗号、分号或换行分隔（例如 `tag1,tag2，tag3`）。空格不会拆开，以便「machine learning」这类多词标签保持完整：

  ![设置标签](https://pic.mereith.com/img/f96db83327831a83b5eb7b010be0f431.clipboard-2022-08-15.png)

- 分类

  选择分类前需要创建分类，具体请参考[分类管理](./tag.md#分类管理)

- 是否加密 & 密码

  选中是否加密并设置好密码之后，前台的文章将被隐藏，需要输入密码之后才能看到内容。密码会在后端验证，并只有匹配时才会把文章数据返回前端。

  ::: danger 访问密码不可找回

  密码在服务端只存 **scrypt 哈希**，任何接口都不回显（后台列表只给一个「有没有设密码」的布尔）。
  **忘记了就没有任何找回手段**，只能在「修改信息」里显式清除或重设；表单语义是「留空 = 不修改」，
  清除加密必须显式打开「清除密码」开关。详见 [加密文章](../advanced/encrypt.md)。

  :::

  ![文章列表](https://pic.mereith.com/img/a694826dd1a45976cc652087640c41c1.clipboard-2022-08-16.png)

  ![文章详情](https://pic.mereith.com/img/fad60a38e0d6819bfe6089108fe4142a.clipboard-2022-08-16.png)

- 题头图 / 封面

  可选。在新建文章或「修改信息」里填写图片 URL，或点「上传图片」走现有图床。设置后，文章页顶部会显示这张图，分享到飞书 / 知乎等应用时也会作为 `og:image` / `twitter:image` 预览图。留空则不显示，已有文章的版式不变。导入 Markdown 时，Front Matter 的 `cover`（或 `image`）会预填到该字段。

- 是否隐藏

  选择隐藏后，前台将不会显示该文章的所有信息，该文章也不会计入总字数、标签、分类数量统计或者出现在时间线界面。但后台将正常显示该文章，并可以取消隐藏状态。

  文章管理一级表格有「是否隐藏」列（开关显示「是 / 否」），可直接切换，不必打开「操作 → 修改信息」或编辑器。开关走现有的更新文章接口。较窄的屏幕也会显示该列。仍可在「修改信息」里改同一字段。

前台时间线/分类页以及后台「总字数」等于各篇**已发布**文章在编辑器中显示的字数之和（中文按字、英文按词，不是字节数）。草稿与隐藏文章不计入。

前台「时间线」按年分组，年份之下再按月分类（例如 `2024` → `12月` / `3月`）。只有真正有文章的月份会显示，不会列出空月份。分类页和标签页仍按原来的方式分组。

## 导入文章

你可以点击 `导入` 按钮导入 Markdown 文件来创建文章。列表页的导入接受 `.md`；
**`.mdz`（Typora 图片包）走编辑器的「导入内容」**（右上角操作按钮，选择器接受 `.md,.mdz`）：

- **`.md`**：普通 Markdown，Front Matter 会被解析成确认表单里的字段（见下表）；
- **`.mdz`**：本站「Typora 图片包」导出格式（一个 zip：相对链接的 md + `<标题>.assets/` 图片目录）。
  导入是导出的**精确逆操作**：图片走正常上传管线入图床（按内容去重、自动生成缩略图），
  正文里的相对链接改写成图床 URL，标题/正文/Front Matter 填进编辑器 —— **不会自动建文章**，
  由你审阅后自己保存。⚠️ Front Matter 里的 `password` 会被**直接丢弃**（不回填、不进日志：
  访问密码只存哈希，导入的明文没有意义），`private: true` 会保留，
  文章维持加密状态（密码需要导入后重设）。

![导入 Markdown](https://pic.mereith.com/img/537490f086ff26ab0b339bd68f7f9016.clipboard-2022-08-29.png)

其中，Markdown 文件的 [Front Matter](https://hexo.bootcss.com/docs/front-matter.html) 将会被自动解析成 VanBlog 的字段并展示在弹出的确认表单中，具体而言：

| 字段名称   | 映射到 VanBlog 中的字段 | 说明                                              |
| ---------- | ----------------------- | ------------------------------------------------- |
| title      | 标题                    | 默认使用文件名                                    |
| tags       | 标签                    | 默认为空                                          |
| categories | 分类                    | 会选择第一个包含在 Vanblog 系统中的分类，否则为空 |
| category   | 分类                    | 会选择第一个包含在 Vanblog 系统中的分类，否则为空 |
| date       | 创建日期                | 如果默认为当前时间                                |
| hide       | 是否隐藏文章            | 默认不隐藏                                        |
| hidden     | 是否隐藏文章            | 默认不隐藏                                        |
| password   | 是否加密/密码           | 如果有，则文章自动为加密，且该字段为密码          |
| top        | 置顶优先级              | 默认为 0                                          |
| pathname   | 自定义路径名            | 与新建文章相同；发布后地址为 `/post/[自定义路径名]`。优先于 `slug` / `url` / `abbrlink` |
| slug       | 自定义路径名            | Hugo 的 slug。未写 `pathname` 时用此值预填，对应 `permalinks.post = "/post/:slug"` |
| url        | 自定义路径名            | 仅识别单段路径或 `/post/<slug>`，不会解析 `/:year/:month/:title` 一类模板 |
| abbrlink   | 自定义路径名            | hexo-abbrlink / hexo-addlink。若未写 `pathname` / `slug` / `url`，用此值预填，便于把 `archives/cb933e30.html` 迁成 `/post/cb933e30` |
| cover      | 题头图                  | 可选。文章页顶部封面，同时作为分享预览图。未写 `cover` 时也会读 `image` |
| image      | 题头图                  | 未写 `cover` 时用此值预填 |

选择文件后，会弹出确认窗口（含自定义路径名，可改预填值），您可以在这里继续编辑或修改信息：

![信息确认](https://pic.mereith.com/img/1f0d74ef0ac87dd8f4b6e3e65b84bf84.clipboard-2022-08-29.png)

## 编辑文章

在文章页面的表格点击编辑按钮，即可跳转到编辑器编辑文章。

正文支持 CommonMark / GFM，也可以直接嵌入常见 HTML（如 `<u>`、`<font>`、`<center>`、带 `style` 的标签、`<iframe>`）。前台与后台预览同一套管线；`<script>` 和事件处理属性会被去掉，站点级 JS 请用 [定制化](../advanced/customizing.md)。详见 [编辑器 · 在 Markdown 里写 HTML](../faq/usage.md#文章里写的-html-不生效)。

![文章编辑](https://pic.mereith.com/img/577da489715c94c183247ba63887aac5.clipboard-2022-08-30.png)

如需修改文章信息，点击 `操作/修改信息` 按钮即可。

::: tip 自动实时保存

编辑文章时会自动实时保存内容到本地缓存，此功能默认关闭，可在编辑器右上角下拉菜单中的 `偏好设置` 中开启。

即使没有点击保存按钮就退出了编辑器，下次进入后也会自动恢复上次的状态。

## 导出文章

你可以在文章管理页面操作栏下拉菜单中点击`导出`来导出文章，或者通过在编辑器中的导出按钮来导出文章。
导出时会自动映射信息到 Markdown 文件的 FrontMatter 中。

导出是**下拉三选一**（不再永远给一个外层 zip）：

| 选项 | 拿到的文件 | 什么时候用 |
| --- | --- | --- |
| **Markdown (.md)** | `<标题>.md`，正文原样，图片链接仍指向站点；服务端**完全不抓图**，最快 | 只要文字、或粘到别处继续写 |
| **Typora 图片包 (.mdz)** | 一个 zip：相对链接的 md + `<标题>.assets/` 图片目录，解压即可离线阅读 | 要离线打开、搬到别的编辑器/仓库，或之后用 [`.mdz` 导入](#导入文章)搬回来 |
| **全部打包 (.zip)** | `.md` + `.mdz`（有图才有）+ `导出说明.md`（有跳过/失败的图才有），即一直以来的行为 | 一次拿全；接口不传 `format` 时也是它 |

正文没有可打包图片时选 `.mdz` 会得到明确的 400 提示（那种情况 `.mdz` 与 `.md` 等价），
后台会把它翻译成友好的提示并建议你改选 `.md`。细节（图片抓取规则、文件名清洗、接口契约）见
[导入导出 → 导出单篇文章](../advanced/backup.md#导出单篇文章含图片)。

列表页多选后的**批量导出**是另一条路：在浏览器端把每篇转成 `.md` 直接下载，
不经过服务端、不含图片。要连图片一起带走，请逐篇用 `.mdz`。

## 删除文章与回收站

删除文章（列表操作或编辑器里的删除）现在是**软删除进回收站**：文章立刻从前台消失，
但数据还在。`文章管理 → 回收站` 里可以：

- **恢复**：文章回到列表，重新可见（会触发增量渲染）；
- **彻底删除**：全站唯一的硬删除入口，需要显式二次确认，**不可撤销**，并连带清理该文章的历史版本。

草稿也有同样的回收站（`草稿管理 → 回收站`），见 [草稿管理](./draft.md)。

## 历史版本（revisions）

每次保存**真的改动了标题或正文**时，server 会自动给这篇文章存一个快照（只改分类/标签等
元数据不产生快照）。编辑器右上角操作菜单里有「历史版本」抽屉：

- 列出版本的时间与差异概要，可以查看某一条的完整内容；
- **恢复**一个历史版本；恢复前会先把「当前状态」也存成一条新版本 ⇒ **回滚本身可回滚**；
- 每篇保留条数有上限：`VANBLOG_ARTICLE_REVISIONS_KEEP`（默认 **10**，`0` = 关闭该功能）。
  默认开启的代价很小（实测单条均值 ≈3.1KB，59 篇 × 10 ≈ 1.76MB），换来的是
  「改坏了/被协作者覆盖了」能自己救回来；
- 彻底删除文章时历史版本一起清掉；草稿不记版本。

## 定时发布（publishAt）

在「修改信息」（列表操作 → 修改信息，或编辑器右上角 → 修改信息）里可以设置**定时发布**时间：

- **到点前，这篇文章在所有公开面都不可见**：列表、搜索、RSS、sitemap、相关文章、
  密码解锁接口全都被同一个 `publishAt <= now` 过滤器挡住（标题也不会泄露）；
- 到点后**自动可见**，不需要任何人在场：可见性是查询层的事，每分钟一次的定时任务
  负责触发页面重渲染与清理缓存，所以最迟一分钟内前台就会刷出来；
- 后台文章列表有「定时」状态列，一眼能看出哪些文章在排队；
- 想取消定时，在表单里**清空**该字段即可（前端会显式提交 `null`，不会清不掉）；
- 设了一个过去的时间会当场警告（等于「立即发布」）。

::: tip 与「隐藏」的区别

`hidden` 是人工开关，忘了关就一直藏着；`publishAt` 到点自动翻转，适合「写好了先囤着，
周五早上八点发」这种场景。两者独立：定时到点但 `hidden` 开着的文章仍然不可见。

:::

## 阅读时长与相关文章

- **阅读时长**：文章页与列表卡会显示估算的阅读时长。服务端按 `字数 ÷ 阅读速度` 计算
  （`VANBLOG_READING_SPEED_WPM`，默认 350 字/分钟，夹在 50–2000）；
  私有/加密文章不给（正文藏着，长度也就藏着）。
- **相关文章**：文章页底部最多列出 5 篇相关文章（按分类/标签相关度），
  私有、加密、隐藏与未到点的定时文章都不会出现。

## 批量操作

文章管理页面支持批量操作，可以批量删除或者批量导出。
