## 问题反馈

遇到问题请到 [CKboss/vanblog 开一个 Issue](https://github.com/CKboss/vanblog/issues/new)。
为了让问题一次就能被看懂，报问题时请带上这三样：

1. `./vanblog.sh status` 的输出；
2. `./vanblog.sh log` 里相关的几行（或后台「站点管理 / 日志管理」的截图）；
3. 后台「关于」页显示的版本号（形如 `v2026.9.2@23f2e9c`）。

⚠️ 贴日志前请顺手抹掉密码、token、域名解析密钥这类敏感信息。
