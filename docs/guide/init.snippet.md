部署 VanBlog 后，请使用浏览器打开 `http://<你的域名>/admin/init`，并按照指引完成初始化。具体设置项可以参考 [站点配置](/features/config.md)。

你也可以直接访问博客地址，并点击导航栏右上角管理员按钮进入后台初始化页面。

初始化一共有三条路，按需选一条：

1. **初始化向导**（默认）：在初始化页填写管理员账号与站点信息；
2. **从整站备份恢复**：初始化页**最上方**有「已有整站备份？直接恢复」卡片，上传一份
   `vanblog-full-*.tar.zst` 就能把旧站整站搬过来，**不用先填一遍向导**，
   恢复完成后用备份里的账号登录（见 [导入导出 → 在新机器的初始化页直接恢复](/advanced/backup.md#在新机器的初始化页直接恢复不用先建管理员)）；
3. **环境变量零接触初始化**：给容器设置 `VANBLOG_ADMIN_USER` + `VANBLOG_ADMIN_PASSWORD`
   （或 `VANBLOG_ADMIN_PASSWORD_FILE`），站点会在**监听第一个 HTTP 请求之前**完成初始化，
   全程不需要打开浏览器，见下面的[「零接触初始化」](/guide/init.md#零接触初始化环境变量直接建好管理员)。

::: tip

如果你直接使用默认的 80 和 443 端口，并且不打算套反代，

直接访问 `https://<你的域名>/admin/init`，VanBlog 会自动为你访问的域名签发证书，并开启 HTTPS。

这个过程可能会比较慢，取决于域名解析验证的时长。

具体请参考 [HTTPS](/advanced/https.md)。

如果需要套反向代理，请参考 [反代](/reference/reverse-proxy.md)。

:::
